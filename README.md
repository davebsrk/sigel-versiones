# SIGEL — versiones

Versiones compiladas de **SIGEL** (Sistema de Gestión Estudiantil Lossada), del C.E.N. Dr. Jesús Enrique Lossada.

Este repositorio solo guarda el programa (`SIGEL.exe`) en la sección **Releases**. El código fuente y los datos de los estudiantes están en un repositorio privado.

SIGEL revisa este repositorio al abrir y, si hay una versión nueva, ofrece instalarla. La actualización cambia solo el programa: la base de datos del colegio no se toca.
